# 원본문제·원본해설 불변 원칙

> 총괄마스터 이하 모든 에이전트의 절대 원칙입니다.

## 1. 절대 금지

- 원본 문제 PDF를 수정, 덮어쓰기, 재작성, 정규화하지 않는다.
- 원본 정답·해설 PDF를 수정, 요약본으로 대체, 재작성하지 않는다.
- 공식 해설 또는 이미 존재하는 해설 텍스트를 더 좋은 표현으로 바꿔 쓰지 않는다.
- DB/Obsidian 동기화 과정에서 원본 문제·원본 해설 내용을 사람이 검수한 추가 해설로 덮어쓰지 않는다.

## 2. 허용

- 원본 PDF에서 crop 이미지, OCR 텍스트, 메타데이터를 파생 생성할 수 있다.
- 추가 해설, 대안 풀이, 학생 친화 풀이, 오답 해설은 별도 필드/별도 노트/별도 테이블에 추가할 수 있다.
- 원본과 파생물은 항상 구분한다.

## 3. 저장 구분

| 종류 | 예시 | 상태 |
|---|---|---|
| 원본문제 | `sources/**/*.pdf` 중 문제지 | 불변 |
| 원본정답 | `sources/**/*.pdf` 중 정답지 | 불변 |
| 원본해설 | `sources/**/*.pdf` 중 해설지 | 불변 |
| 파생 이미지 | `sources/crops/*.jpg` | 재생성 가능 |
| OCR/요약 | `raw_text`, 문제 노트 본문 | 파생물 |
| 추가 해설 | `stage3_solution`, 별도 해설 노트 | 추가 가능 |

## 4. 운영 규칙

- 새 원본 파일을 추가하면 `Integrity Guard` 기준선을 갱신한다.
- 기준선 이후 원본 파일의 해시가 바뀌면 즉시 중단하고 복구한다.
- 에이전트는 원본을 편집 대상으로 삼지 않는다.
- 해설을 만들 때는 “원본 해설”과 “추가 해설”을 명시적으로 분리한다.

## 5. 점검 명령

```powershell
python agents\integrity_guard_agent.py --audit
```

새 원본을 등록한 직후에만 기준선을 갱신합니다.

```powershell
python agents\integrity_guard_agent.py --baseline
```
