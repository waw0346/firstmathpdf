# 📖 수학의 지름길 — Obsidian 활용 가이드

## 🎯 4가지 핵심 활용법

### 1. 문제 검색 & 호출
```
단원으로: 00_VISUAL_DASHBOARD.md → 단원별 분포 클릭
난이도로: 검색창(Ctrl+Shift+F) → difficulty: 상
연도로:   00_VERIFY.md → 연도 필터
```

### 2. 복습 시스템 (Spaced Repetition 설치 후)
```
문제 페이지 하단에 추가:
#flashcard
Q: f(x) = (x²+1)(3x²-x) 에서 f'(1)은?
A: 10 (②번)
```

### 3. 풀이 기록 (Excalidraw 설치 후)
```
문제 페이지에서 Ctrl+P → "Excalidraw" → New Drawing
풀이 과정을 직접 그림 → 저장 시 자동 링크
```

### 4. 그래프 뷰 활용
```
Ctrl+G → 그래프 뷰
필터: path:wiki/problems
유사문제 연결망 시각화
```
