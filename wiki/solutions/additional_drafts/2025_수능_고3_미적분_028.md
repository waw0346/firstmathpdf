### 1. 접근 전략

본 문항은 **이계도함수를 통한 곡선의 볼록성 판정**, **정적분으로 정의된 함수의 미분**, **부분적분법을 활용한 식의 소거**, 그리고 **치환적분법**까지 미적분 교과 전체의 핵심 개념들이 유기적으로 결합된 고난도 문항입니다. 실전에서 헤매지 않기 위해 다음 4단계 전략을 수립합니다.

1. **곡선의 요철(볼록성) 판정**: 접선과 곡선으로 둘러싸인 영역의 넓이 $g(t)$의 식을 올바르게 세우기 위해, 이계도함수 $f''(x)$의 부호를 조사하여 접선과 곡선의 대소 관계를 파악합니다.
2. **변수 분리를 통한 $g(t)$ 식 정리**: $g(t)$의 정적분 식에서 적분 변수 $x$와 미분 변수 $t$를 분리하여, 미적분학의 기본 정리(Leibniz Rule)를 적용할 수 있는 형태로 재구성합니다.
3. **$g'(1)$ 계산**: 정리된 $g(t)$를 미분하여 $g'(t)$를 구하고, $t=1$을 대입합니다.
4. **부분적분을 활용한 $g(1)$ 계산 (소거법)**: $g(1)$을 구하는 식에서 직접 구할 수 없는 원함수값 $f(1)$을 소거하기 위해, $\int_0^1 f(x) \, dx$에 부분적분법을 적용합니다. 이후 남은 식은 치환적분법으로 해결합니다.

### 2. 핵심 계산

#### **[Step 1] 곡선의 볼록성 판정**
주어진 도함수 $f'(x) = -x + e^{1-x^2}$를 $x$에 대해 한 번 더 미분하여 이계도함수 $f''(x)$를 구합니다.
$$f''(x) = -1 - 2x e^{1-x^2}$$

문제에서 양수 $t$에 대하여 다루고 있으므로, $x > 0$인 영역에서의 부호를 조사합니다.
- $x > 0$일 때, $2x > 0$이고 $e^{1-x^2} > 0$이므로, $-2x e^{1-x^2} < 0$입니다.
- 따라서 $x > 0$인 모든 실수 $x$에 대하여 **$f''(x) < -1 < 0$**이 성립합니다.
- $f''(x) < 0$이므로 곡선 $y=f(x)$는 이 구간에서 **위로 볼록(Concave Down)**합니다.
- 위로 볼록한 곡선의 접선은 접점을 제외한 모든 곳에서 곡선보다 위쪽에 위치하므로, 다음 대소 관계가 성립합니다.
$$\text{접선의 } y\text{값} \ge \text{곡선의 } y\text{값} \implies f(t) + f'(t)(x-t) \ge f(x)$$

#### **[Step 2] 넓이 함수 $g(t)$의 식 세우기 및 변수 분리**
$y$축($x=0$)과 접선, 곡선 및 $x=t$로 둘러싸인 넓이 $g(t)$는 다음과 같이 정적분으로 정의됩니다.
$$g(t) = \int_{0}^{t} \left\{ \left[ f(t) + f'(t)(x-t) \right] - f(x) \right\} dx$$

여기서 적분 변수는 $x$이므로, $t$에 관한 식들을 정적분 기호 밖으로 꺼내기 위해 식을 전개합니다.
$$g(t) = \int_{0}^{t} \left\{ f'(t)x + \left[ f(t) - t f'(t) \right] - f(x) \right\} dx$$
$$g(t) = f'(t) \int_{0}^{t} x \, dx + \left[ f(t) - t f'(t) \right] \int_{0}^{t} 1 \, dx - \int_{0}^{t} f(x) \, dx$$
$$g(t) = f'(t) \left[ \frac{1}{2}x^2 \right]_0^t + \left[ f(t) - t f'(t) \right] [x]_0^t - \int_{0}^{t} f(x) \, dx$$
$$g(t) = \frac{1}{2}t^2 f'(t) + t f(t) - t^2 f'(t) - \int_{0}^{t} f(x) \, dx$$
$$g(t) = t f(t) - \frac{1}{2}t^2 f'(t) - \int_{0}^{t} f(x) \, dx$$

#### **[Step 3] $g'(t)$ 구하기 및 $g'(1)$ 계산**
위에서 얻은 $g(t)$ 식의 양변을 $t$에 대해 미분합니다. 곱의 미분법과 정적분으로 정의된 함수의 미분을 적용합니다.
$$g'(t) = \frac{d}{dt} \left[ t f(t) - \frac{1}{2}t^2 f'(t) - \int_{0}^{t} f(x) \, dx \right]$$
$$g'(t) = \left( f(t) + t f'(t) \right) - \left( t f'(t) + \frac{1}{2}t^2 f''(t) \right) - f(t)$$

동류항을 정리하면 놀랍게도 많은 항들이 소거되어 아래와 같이 단순해집니다.
$$g'(t) = -\frac{1}{2}t^2 f''(t)$$

이제 $t=1$을 대입하여 $g'(1)$을 구합니다.
$$g'(1) = -\frac{1}{2}(1)^2 f''(1) = -\frac{1}{2} f''(1)$$
앞서 구한 $f''(x) = -1 - 2x e^{1-x^2}$에 $x=1$을 대입하면:
$$f''(1) = -1 - 2(1)e^0 = -3$$
따라서,
$$g'(1) = -\frac{1}{2} \times (-3) = \frac{3}{2}$$

#### **[Step 4] $g(1)$ 구하기 (부분적분과 치환적분)**
[Step 2]의 $g(t)$ 식에 $t=1$을 대입합니다.
$$g(1) = f(1) - \frac{1}{2}f'(1) - \int_{0}^{1} f(x) \, dx$$

이때 $f'(1)$의 값을 구해보면:
$$f'(1) = -1 + e^{1-1^2} = -1 + e^0 = 0$$
이므로 $f'(1) = 0$ 항은 사라지고 식은 다음과 같이 정리됩니다.
$$g(1) = f(1) - \int_{0}^{1} f(x) \, dx$$

우리는 $f(x)$를 직접 구하기 어려우므로, 정적분 항 $\int_{0}^{1} f(x) \, dx$에 **부분적분법**을 적용하여 $f(1)$을 소거합니다.
- 미분할 함수: $u = f(x) \implies u' = f'(x)$
- 적분할 함수: $v' = 1 \implies v = x$
$$\int_{0}^{1} f(x) \, dx = \left[ x f(x) \right]_0^1 - \int_{0}^{1} x f'(x) \, dx = f(1) - \int_{0}^{1} x f'(x) \, dx$$

이를 $g(1)$ 식에 대입하면 $f(1)$이 소거되는 마법 같은 결과를 얻습니다.
$$g(1) = f(1) - \left( f(1) - \int_{0}^{1} x f'(x) \, dx \right) = \int_{0}^{1} x f'(x) \, dx$$

이제 주어진 $f'(x) = -x + e^{1-x^2}$를 대입하여 계산합니다.
$$g(1) = \int_{0}^{1} x \left( -x + e^{1-x^2} \right) dx = -\int_{0}^{1} x^2 \, dx + \int_{0}^{1} x e^{1-x^2} \, dx$$

1. **첫 번째 항**:
   $$-\int_{0}^{1} x^2 \, dx = -\left[ \frac{1}{3}x^3 \right]_0^1 = -\frac{1}{3}$$
2. **두 번째 항 (치환적분)**:
   $1-x^2 = s$로 치환하면, $-2x \, dx = ds \implies x \, dx = -\frac{1}{2} ds$ 입니다.
   - 적분 구간: $x=0 \implies s=1$, $x=1 \implies s=0$
   $$\int_{0}^{1} x e^{1-x^2} \, dx = \int_{1}^{0} e^s \left( -\frac{1}{2} ds \right) = \frac{1}{2} \int_{0}^{1} e^s \, ds = \frac{1}{2} \left[ e^s \right]_0^1 = \frac{1}{2}(e-1)$$

따라서 $g(1)$은 다음과 같습니다.
$$g(1) = -\frac{1}{3} + \frac{1}{2}e - \frac{1}{2} = \frac{1}{2}e - \frac{5}{6}$$

---

### 3. 정답 확인

구하고자 하는 값은 $g(1) + g'(1)$이므로 각각의 구한 값을 대입합니다.
$$g(1) + g'(1) = \left( \frac{1}{2}e - \frac{5}{6} \right) + \frac{3}{2} = \frac{1}{2}e - \frac{5}{6} + \frac{9}{6} = \frac{1}{2}e + \frac{4}{6} = \frac{1}{2}e + \frac{2}{3}$$

따라서 구하는 정답은 **②번**입니다.

### 4. 학생 주의점 및 오개념 방지 팁

#### **🚨 오개념 1: 정적분 변수와 미분 변수의 혼동 (Leibniz 공식의 기계적 적용 오류)**
- **실수 유형**: 많은 학생들이 $g(t) = \int_{0}^{t} \left\{ f(t) + f'(t)(x-t) - f(x) \right\} dx$ 식을 보고, 기계적으로 피적분함수의 $x$ 자리에 상한 $t$를 대입하여 $g'(t) = f(t) + f'(t)(t-t) - f(t) = 0$과 같이 잘못 미분합니다.
- **방지 대책**: 피적분함수 내에 적분 변수($x$) 외에 **미분 변수($t$)가 포함되어 있는 경우, 절대로 바로 미분할 수 없음**을 강조해야 합니다. 반드시 $t$가 포함된 항을 분리하여 적분 기호 밖으로 꺼낸 후, **곱의 미분법**을 사용해 미분해야 함을 시각적으로 단계를 나누어 지도해야 합니다.

#### **🚨 오개념 2: 구해지지 않는 원함수 $f(x)$를 구하기 위한 무한 루프**
- **실수 유형**: $g(1) = f(1) - \int_{0}^{1} f(x) \, dx$ 식을 마주한 후, $f(x)$를 직접 구해야만 문제를 풀 수 있다고 착각하여 $f'(x) = -x + e^{1-x^2}$를 적분하려고 시도합니다.
- **방지 대책**: 고등학교 교육과정 범위에서 $e^{-x^2}$ 꼴의 함수는 부정적분을 초등함수로 나타낼 수 없는 대표적인 **'적분이 불가능한 함수'**임을 상기시킵니다. 수능 수학에서 원함수를 직접 구하기 어려운 정적분 식이 주어졌을 때는 **부분적분법($\int 1 \cdot f(x) \, dx$)을 통해 $f(x)$를 $f'(x)$가 포함된 식으로 변환하여 조건식을 소거하는 패턴**이 핵심 열쇠임을 인지시켜야 합니다. (이른바 '소거의 마법' 패턴)

#### **🚨 오개념 3: 접선과 곡선의 대소 관계(볼록성) 판단 생략**
- **실수 유형**: 넓이 식을 세울 때 직관적으로 곡선이 위인지 접선이 위인지 판단하지 않고 아무렇게나 식을 세웠다가, 결과가 음수로 나오거나 미분 시 부호가 꼬여 오답을 냅니다.
- **방지 대책**: 넓이를 정의할 때는 반드시 **이계도함수 $f''(x)$를 통해 그래프의 요철을 먼저 정의하는 습관**을 들여야 합니다. $x>0$에서 $f''(x) < 0$이므로 '위로 볼록'하고, 따라서 접선이 곡선보다 항상 위쪽에 있음을 수학적으로 명쾌하게 밝히고 시작하는 것이 감점을 막는 지름길입니다.

#### **🚨 오개념 4: 치환적분 시 적분 구간 및 부호 실수**
- **실수 유형**: $1-x^2 = s$로 치환하는 과정에서 적분 구간을 $0 \to 1$ 그대로 유지하거나, $dx = -\frac{1}{2x} ds$의 마이너스 부호를 빠뜨려 최종 계산에서 오답을 도출합니다.
- **방지 대책**: 치환적분을 수행할 때는 항상 **[치환 관계식 $\to$ 양변 미분 및 $dx$ 정리 $\to$ 적분 구간 변환 표]**를 노트 한쪽에 완벽히 적어두고 대입하는 정형화된 풀이 프로세스를 훈련시킵니다.
