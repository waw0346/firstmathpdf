# 📖 Obsidian 검수 시스템 사용법

## 🔄 검수 워크플로우

```
1. Obsidian에서 00_VERIFY.md 열기
        ↓
2. "검수 대기" 목록에서 문제 클릭
        ↓
3. 문제 이미지 확인 (자동 표시됨)
        ↓
4. 우측 Properties 패널에서 값 수정
        ↓
5. 모든 문제 검수 완료 후
   "검수완료_DB반영.bat" 더블클릭
        ↓
6. DB에 자동 반영 + 00_VERIFY.md 갱신
```

---

## ✏️ Properties 패널 수정 값

### 1단계 - 이미지 검수
| `stage1_img` | 의미 |
|---|---|
| `pass` | ✅ 이미지 정상 (문제+선택지 온전히 보임) |
| `fail` | ❌ 이미지 오류 (잘림, 없음 등) |

### 2단계 - 정답 검수
| `stage2_ans` | 의미 |
|---|---|
| `pass` | ✅ 정답 정확 |
| `fixed` | 🔧 정답 수정 (`answer_fixed` 필드에 올바른 정답 입력) |
| `fail` | ❌ 정답 오류 |

### 3단계 - 해설 검수
| `stage3_sol` | 의미 |
|---|---|
| `pass` | ✅ 해설 완료 (`stage3_solution`에 풀이 입력) |
| `fail` | ❌ 해설 필요 |

### 최종 서명
| 필드 | 입력값 |
|---|---|
| `sign_tr` | `tr✓ 2026-05-30` |
| `sign_cp` | `cp✓ 2026-05-30` |

---

## 🏆 최종 등급 자동 계산

| 조건 | 등급 |
|---|---|
| 1단계✅ + 2단계✅ + 3단계✅ | **A등급** (완전) |
| 1단계✅ + 2단계✅ | **B등급** (해설 미완) |
| 1단계❌ 또는 2단계❌ | **C등급** (재작업) |

---

## 💾 DB 반영 방법

검수 완료 후:
```
검수완료_DB반영.bat  ← 더블클릭
```

또는 터미널:
```bash
python scripts/sync_from_obsidian.py
```
