# 🔗 유사문제 생성 시스템 — 단계별 계획

> **핵심 원칙**: 원본 이미지 불변 | raw_text AI 100% 전까지 보류
> **방법**: 이미지+메타데이터+선생님 수작업 협력

---

## 🏗️ 3단계 구현 로드맵

### Stage 1 — 현재 즉시 가능 ✅

```
메타데이터 기반 자동 그룹화:
  topic + difficulty → 유사 후보 자동 생성
  예: '미분_하' 그룹 → 수능2025·수능2026·6월모의 같은 유형 10개
```

**현재 구축된 것:**
- 유사문제 쌍: **370개** (기존)
- 자동 유사그룹: **43개** (신규)
- similar_groups 테이블

---

### Stage 2 — 선생님 수작업 협력 (핵심) 📝

**Mi 선생님이 직접 하는 것:**
1. 문제 페이지에서 개념 태그 입력
2. 유사문제 그룹 연결
3. 풀이 핵심 키워드 입력
4. 변형 방향 메모 (숫자변경/조건변경/역문제)

```
문제 Properties에 추가:
  concept_tags: [곱의미분법, 미분계수 정의]
  similar_type: 계산형
  solution_key: f'(x)=미분후대입
  variation_note: 함수만 바꾸면 유사문제 생성 가능
```

**태그 체계:**
```
tag_type     예시
──────────────────────────────
concept      곱의미분법, 로그미분, 치환적분
type         계산형, 추론형, 증명형, 조건형
key          공식대입, 극한정의, 수열점화식
variation    숫자변경 / 조건변경 / 역문제 / 심화
```

---

### Stage 3 — 이미지 임베딩 (부분 가능) 🖼️

```
문제 이미지 → 시각 패턴 유사도
(수식 인식 X, 레이아웃·구조 패턴만)
→ "비슷한 조건박스 구조" 탐지
→ "비슷한 그래프 형태" 탐지
```

---

### Stage 4 — AI 완전 연동 (미래) 🤖

```
조건: AI 수식 인식 100% 달성 시
     → raw_text 자동 추출
     → 개념 자동 태깅
     → 유사문제 자동 생성
     → 변형 문제 AI 출제

현재는: 이미지 + 메타데이터로 기반 완성 → AI 연동 준비
```

---

## 📊 현재 유사문제 그룹 현황

```dataview
TABLE topic AS "단원", difficulty AS "난이도", 
      length(similar_ids) AS "유사문제수"
FROM "wiki/problems"
WHERE similar_ids AND length(similar_ids) > 3
SORT length(similar_ids) DESC
LIMIT 15
```

---

## ✏️ 선생님 태깅 방법

1. 문제 페이지 열기
2. **Properties 패널**에서:
   ```
   concept_tags: 곱의미분법
   solution_key: 공식대입후계산
   variation_note: 함수종류변경가능
   ```
3. `검수완료_DB반영.bat` 실행
